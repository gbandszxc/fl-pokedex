详情面板**不用页签**：五段（图鉴说明 / 种族值 / 进化 / 招式 / 资料）自上而下依次追加，
单列滚动；右侧常驻**分区锚点轨**（固定宽 56，左缘 1px outlineVariant 分隔线，底色 surface）
五段各一枚「图标 + 两字短名」，完整名进 Tooltip。点按跳转——落点是分区标题贴着 pinned
SliverAppBar 之下 8px（不是视口最顶端）；滚动时高亮当前段（激活项 primary 着色 + 左缘 2px 指示条）。
双栏嵌入的详情面板与全页路由详情是同一主体，锚点轨两者都有。compact/medium 仍用页签。

内容宽 ≥1100（窗口 ≥1204 的全页宽屏 / 超宽屏的双栏面板）：切换**双列瀑布**——
立绘收成横排头部（左立绘 180 高 / 槽宽 260，右侧编号、名称、属性、分类与形态 chips），
五段分左右两列：左列「档案」图鉴说明 → 种族值 → 资料；右列「对局」进化 → 招式；
列间 24px。招式折叠后两列高度接近，一屏即可总览。锚点轨照常（跳转钉定；滚动跟随
改「最近过线段」口径，单列下与原口径等价）。内容宽 840–1100 仍为单列 + 锚点轨。

```

```

```
        [心金/魂銀] [LEGENDS 阿尔宙斯] …                ← 窄面板自动折行
 [全部] [升级] [学习器] [遗传] [导师] [其他]             ← 来源 chips 同款折行

┌─────────────────────────────────────────────┐
│ 名称        属性   分类  威力  命中  PP  等级 │     ← 列头（expanded 只一份，位于分组之上）
│ 撞击       (一般) 物理   40  100   35  Lv.01│
│ 叫声       (一般) 变化    —  100   40  Lv.01│
│ …                                            │
└─────────────────────────────────────────────┘

```

点开「学习器招式」后，该组的行插入本组表头之下，chevron 旋转 180°（`AppMotion.fast`）：

```
学习器招式 · 24 个                            ⌃
  剑舞       (一般) 变化    —    —    20  学习器   ← 行尾无等级 → 显示来源短词
  十万伏特   (电)   特殊   90  100   15  学习器
```

compact：表格简化为两行卡片列表；expanded：完整表格，列头不可点、列宽固定，排序走上方筛选行行尾的「排序 ▾」菜单（等级 / 威力 / 名称）。版本组 / 来源 chips 用 Wrap **自动换行、无横向滚动**（间距 spacing/runSpacing 均为 AppSpacing.s），「排序」固定在版本组行行尾、与首行 chips 顶对齐。
点击行 → /move/:id 全页招式详情（威力/命中/PP/说明/效果/世代）。

**分组与折叠规则**（默认视图求短：妙蛙种子在朱/紫 53 条，全平铺会把下方分区推得很远）：

1. **分组条件**：仅「排序 = 等级」时按来源分组——等级序本身按 `methodGroupOrder` 分块；「威力」「名称」是跨来源排序，分组会把同一排序轴上的行切碎，语义不成立，保持平铺。
2. **分组粒度**：结果只含 1 个来源 → 不显示分组表头（无信息量），平铺；≥2 个来源 → 每个来源一个可折叠分组，组序 升级 → 学习器 → 遗传 → 导师 → 其他，表头为「{来源}招式 · N 个」+ 右侧 chevron（AnimatedRotation）。
3. **默认展开**：无来源筛选 → 只展开第一个分组；有来源筛选（用户已明确缩小来源）→ 全部分组展开。用户显式折叠/展开优先；版本组 / 来源 / 排序任一变化即清空显式状态、回到默认规则。

折叠组**条件渲染**：行不进 widget 树、不占高度。**不做懒加载 / 虚拟化**——默认折叠已把首屏行数压到首组规模，进一步按需构建需要把整页（含分区锚点轨的滚动几何）改成 sliver 组合，收益不足，留待后续阶段。

### 8.1 检查更新（CheckUpdateRow）

启动时**静默检查一次**（`lib/app/update_startup_check.dart`，失败与「已是最新」都不打扰）；
设置页「检查更新」行给出全部反馈：已是最新 / 检查失败走 SnackBar，命中新版本走两个模态。

```
┌ 发现新版本 1.1.0 ──────────────┐   ┌ 正在下载更新 ──────────────────┐
│ 当前版本  1.0.0                │   │ Fl-PokeDex-1.1.0-x86_64-        │
│ 最新版本  1.1.0                │   │              release.apk        │
│ 适用平台  Android · x86_64     │   │ ▓▓▓▓▓▓░░░░░░░░░░░░░░░░          │
│ Fl-PokeDex-1.1.0-x86_64-       │   │ 12.0 MB / 84.0 MB · 4.2 MB/s    │
│              release.apk       │   │                        [取消]   │
│        [稍后] [下载并安装]      │   └────────────────────────────────┘
└────────────────────────────────┘
```

- 安装包**按当前系统与架构自动选择**（Android 认 ABI：arm64-v8a / armeabi-v7a / x86_64；
  Windows 取 x64 MSI；macOS arm64 取 arm64 dmg、x64 取 universal dmg），对话框「适用平台」行明示。
- 进度模态不可点遮罩关闭；「取消」或返回键会中止下载并删除半成品。
- 下载完成即交系统安装流程：Android 拉起系统包安装器（未授权时弹「需要安装权限」→ 前往系统设置；
  安装包已缓存，重试不重复下载），Windows 拉起 `msiexec` 后退出应用，macOS `open` 磁盘映像。
- 用户点「稍后」后本次运行不再自动弹窗；手动入口不受影响。
