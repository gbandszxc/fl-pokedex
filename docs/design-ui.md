配合 DESIGN.md Token 使用。以下为结构示意，落地以 DESIGN.md 的间距/圆角/颜色为准。

## 4. 种族值可视化（原创：居中发散条 + 总和徽章）

```
        种族值                       总和 534
  HP      78 ○────────────●      ← 中轴基线，条形从中轴向右延伸，蜜金单色
  攻击    84 ────────────●           数值 tabular 对齐在左列
  防御    78 ────────────●           长度 = value / 255
  特攻   109 ─────────────────●
  特防    85 ────────────●
  速度   100 ───────────────●
```
Expanded 下右侧另配雷达图（CustomPaint 六边形，网格 3 环 85/170/255，单色描边）。

## 5. 进化树（图结构渲染，非线性链）

```
compact（纵向）：                    expanded（横向树）：
   伊布                              索罗亚克?   ← 根居左，子节点列状展开
    ├─火─ 太阳伊布                    伊布 ─┬─(雷之石)→ 雷伊布
    ├─水─ 月亮伊布                          ├─(水之石)→ 水伊布
    ├─(亲密度+白天)→ 太阳伊布               ├─(火之石)→ 太阳伊布
    └─ …8 分支                          …
分支进化（如 呆呆兽→呆呆王 需王者之证/携带+交换；同时 呆呆兽王 单线）
条件文本用 chip+短语表达：〔Lv.16〕〔亲密度 220〕〔王者之证+交换〕〔夜晚〕
```

## 6. 招式区块（详情页 Tab 内）

```
 版本组 ▾ [朱/紫·蓝碧盘]   [全部|升级|学习器|遗传|导师]   排序 ▾
┌─────────────────────────────────────────────┐
│ 名称        属性   分类  威力  命中  PP  等级 │
│ 火焰旋涡    (火)   特殊   35   85   15  Lv.01│
│ 龙之爪      (龙)   物理   80  100   15  Lv.01│
│ …                                            │
└─────────────────────────────────────────────┘
compact：表格简化为两行卡片列表；expanded：完整表格，列可排序。
点击行 → /move/:id 全页招式详情（威力/命中/PP/说明/效果/世代）。
```

## 7. 筛选面板

```
compact：BottomSheet（r20 顶圆角）        expanded：列表上方筛选条展开行
┌──────────────────────────────┐        ┌─ 世代 [一][二][三]…  属性 (火)(水)…
│ 世代  (一)(二)(三)(四)(五)(六)(七)(八)(九)
│ 属性  (一般)(火)(水)… 双属性匹配 [任一|兼具]
│ 地区  (关都)(城都)(丰缘)…
│ 编号  [1]–[1025]  双端滑杆
│ 特殊  (传说)(幻之)(究极异兽)(超级进化)(超极巨)(地区形态)
│ [重置]                  [应用 128 只]
└──────────────────────────────┘
筛选变更即时生效（搜索 + 筛选可组合，无“应用”步骤；按钮仅展示结果数并关闭面板）。
```
